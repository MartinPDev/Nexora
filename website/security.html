Security

Built Around Control, Protection, and Transparency

Nexora is being designed with a security-first approach for users who want intelligent crypto trading tools without giving up control of their exchange accounts.

Encrypted API Key Handling

Exchange API credentials are designed to be stored using encryption so sensitive access information is protected inside the platform infrastructure.

Non-Custodial Design

Nexora does not take custody of user funds. Users keep their crypto on their own supported exchange accounts.

User-Controlled Exchange Access

Users remain responsible for creating, managing, limiting, and revoking exchange API access directly from their exchange account.

Trading Permission Separation

Nexora is intended to work with trading-focused API permissions. Withdrawal permissions should not be required for normal platform use.

Risk Controls

Position limits, confidence checks, exposure awareness, and strategy rules help keep automated trading decisions structured.

Infrastructure Security

Nexora is being built with protected backend services, HTTPS access, controlled deployments, and separation between public website access and backend systems.

Important Protection Standard

Users Should Never Enable Withdrawal Access

Nexora should only require the minimum exchange permissions needed for supported platform functions. For normal trading use, users should not enable API withdrawal permissions.

This protects users by keeping account ownership and fund withdrawal control inside their own exchange account.

Trust Model

Security Is Not A Feature. It Is The Foundation.

Nexora is being built to earn user trust through clear permission boundaries, transparent risk controls, responsible automation, and a platform design that keeps users in control of their own assets.
